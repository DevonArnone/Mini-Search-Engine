# Self-hosted fonts

Latin-subset variable fonts, served from this application rather than a font CDN.

| File | Family | Axes | License |
|---|---|---|---|
| `Fraunces-Variable.woff2`, `Fraunces-Variable-Italic.woff2` | Fraunces | weight, optical size | SIL Open Font License 1.1 |
| `PublicSans-Variable.woff2`, `PublicSans-Variable-Italic.woff2` | Public Sans | weight | SIL Open Font License 1.1 |
| `JetBrainsMono-Variable.woff2` | JetBrains Mono | weight | SIL Open Font License 1.1 |

Sources: the Fraunces Project Authors (github.com/undercasetype/Fraunces), the Public Sans Project Authors (github.com/uswds/public-sans), and the JetBrains Mono Project Authors (github.com/JetBrains/JetBrainsMono). Files were taken unmodified from the Fontsource distributions of each family.
